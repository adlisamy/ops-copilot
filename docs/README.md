# Project Documentation

This directory contains documentation that evolves alongside the application.

| Directory | Purpose |
| --- | --- |
| `architecture/` | Architecture diagrams and system-design notes. |
| `decisions/` | Architecture decision records (ADRs). |
| `runbooks/` | Operational knowledge used by the future RAG workflow. |
| `learning/` | Personal implementation notes and learning log entries. |

Keep secrets, production logs, customer data, and credentials out of this directory.
